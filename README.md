# Vanilla Belle — FCM Relay

مستودع مستقل ومخصص فقط لسكربت مراقبة حالة الطلبات وإرسال إشعارات FCM
الحقيقية للزبائن (حتى لو التطبيق مقفول تماماً).

## ليش مستودع منفصل عن تطبيق فلاتر؟
- مستودعات GitHub **الخاصة (Private)** محدودة بـ 2000 دقيقة تشغيل مجانية
  بالشهر لـ GitHub Actions.
- سكربت الإشعارات يشتغل كل 5 دقائق تلقائياً = استهلاك كبير جداً للدقائق،
  يفضّي الحصة المجانية خلال أسبوع تقريباً ويوقف الإشعارات بصمت.
- مستودعات **العامة (Public)** عندها دقائق GitHub Actions **غير محدودة
  مجاناً**.
- عشان هيك فصلنا السكربت (اللي ما يحتوي أي كود حساس أو تجاري) بمستودع
  عام منفصل، وخلينا تطبيق فلاتر الأساسي بمستودعه الخاص كما هو.

## هل التطبيق العام هذا يأثر على نشر التطبيق بالمتاجر؟
لا إطلاقاً. آبل وگوگل يراجعون فقط الملف النهائي المبني (APK/IPA)، وما
علاقة لهم بمكان أو حالة كود المصدر.

## المتغيرات السرية المطلوبة
- `FIREBASE_SERVICE_ACCOUNT`: ملف JSON الخاص بحساب خدمة Firebase (يُضاف
  من Settings → Secrets and variables → Actions بهذا المستودع).
